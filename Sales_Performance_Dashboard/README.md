# Sales Performance Dashboard — Power BI

### 📌 Project Overview
This project visualizes sales data to understand revenue patterns, product performance, and monthly trends.

### 🧩 Business Problem
Management needed a dashboard to see:
- Monthly revenue changes  
- Region-wise performance  
- Top-selling products  
- Profit trends  

### 🛠 Tools Used
- Power BI  
- Excel  
- DAX  

### 📂 Steps Followed
- Cleaned raw data  
- Created DAX measures  
- Built revenue, profit, region, product visuals  
- Added filters  

### 📈 Key Insights
- Region X performs best  
- Product Y shows maximum profitability  
- Q3 revenue dips indicate seasonality
